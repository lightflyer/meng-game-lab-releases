## 正在推进的功能

- 招将批量操作：金杯单抽批次、将军盏十连批次，以及整批结束后的奖励汇总。
- 商店、礼包和开箱的数量快捷调整。
- 神秘游商的单品批购，以及按币种选择当前有限库存。
- 界面布局、按钮样式、操作提示和旧运行环境兼容性改进。

功能的实现状态和验证范围以每个版本的说明为准。当前版本的完整游戏内表现仍需人工确认。

## 这个仓库放什么

本仓库专门发布版本信息，只收录说明文档、更新记录和验证状态。程序源码保留在私有开发仓库；这里不提供原始游戏资源、签名材料或玩家数据。

当前没有公开的安装包下载。后续是否提供下载，以具体版本公告为准。
